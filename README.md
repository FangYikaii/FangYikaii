# GitHub Profile Content

This repository contains a GitHub profile README:

- `profile/README.md`: profile page content for a `.github` repository.

For a personal GitHub profile, copy the content from `profile/README.md` into the root `README.md` of a same-name repository, such as `fyk/fyk`.

The dynamic contribution widgets currently use `fyk` as the GitHub username. `SynlysisAI` is shown as an identity badge, without a public organization link until the correct URL is confirmed.
